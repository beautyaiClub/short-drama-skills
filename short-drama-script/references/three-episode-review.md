# 三集联合回归

本套流程默认连续三集为一次联合检查节点，如01–03、04–06；创作者另定频率时从其约定。
单集自检继续保留。回归是工作检查，不是固定剧情结构：不要求每三集反转、表白或解决同一种问题。

## 范围与触发

- 累积完成三份可读单集正本后触发；只有大纲的集数不计为已写。
- 连读这三集全文，并读前一批末场、下一集已有开场或地图入口，检查批次边界。
- 中途修改已回归集时，重看改动位置、相邻接缝、受影响的线索兑现集和先前已关闭问题；不无故全季重审。
- 短篇不足三集时，完结做一轮；不等凑齐三集才修单集阻断问题。

## 内容矩阵

每集一行，用剧本事实填“当前目标 → 阻力与选择 → 局部回报 → 未结代价 → 尾钩 → 下集如何接住”。
连看三行，判断是否真在推进，不能只复制同一事故、救援、误会、查证或“好像有回应”。

| 项目 | 连读时检查 | 问题证据 |
|---|---|---|
| 台词 | 同一人的语域与礼貌程度、接话、重复、翻译腔、过度说明；称呼是否符合相识进度 | 引具体句及前后回应；复用不自动等于缺陷 |
| 方向 | 女主目标是否推进或有因果地改变；行动是否留下代价；关系是否靠双方选择发展 | 对照三集起止状态，指出策略或关系是否原地踏步 |
| 钩子与兑现 | 前集问题在后集如何处理；新线索是否增加身份、位置、风险或可行动性 | 不能连续换表述拖同一个答案；未知信息也不能被提前确认 |
| 回报与节奏 | 除受压外，观众得到了什么已发生的成功、亲近或认知变化；段落是否全同强度 | 静戏可以处理后果，不按固定秒数或反转次数判平淡 |
| 连续性 | 时间、场所、伤势、左右手、物件来源、资源、知情权限、世界规则 | 逐接缝追踪；大纲说“已验证”不能代替正文里的验证 |
| 执行与篇幅 | 动作能否同做，表演是否可见，摄影是否承接，规定片长内是否过密 | 整合稿以预算、试读和预演分开记录，不按说明字数冒充实测 |
| 支持文档 | 正本与地图、全局设定、台词映射、派生件及旧审查记录是否一致 | 以正本事实修来源投影，再用脚本重建派生件 |

## 处理与记录

1. 先机械检查，再连读；对内容问题记录位置、短引文、影响、修订目标和波及集数。
2. 区分阻断事实、实质内容问题与可选品味；不凭“感觉平”给分或声称市场留存率。
3. 审查与编辑分开记录。已有修订授权时继续修正并回看；只受托审查时只交问题。
4. 每轮新建 `审查/EP001-003-三集回归-第N轮.md` 等记录；修后核对原问题及回退，不能靠“已修改”三个字关项。
5. 说明作者自检还是独立审查；无独立 reviewer 时照实记录，不伪造签发。
6. 重大未解问题先修再扩写依赖它的下一批；不涉及的问题仍可推进，也不把创作建议变成额外审批。

报告至少保留：三集推进矩阵、发现与处理、两处集间接缝及批次出口、尚待试读或预演的事项。
机械通过、作者回看和母语表演验证分别报告；不得合称“全面验证通过”。
