# 派生件：台词对照本与分集场次表

这两份文件**只由脚本生成**：它们与正本脱钩是这套流程里最常见、也最贵的翻车点
（配音拿到旧台词、统筹按旧场号排期、客户看到的包与项目不一致）。

## 1. 台词对照本

结构（与正本逐条对应，顺序也一致）：

```text
寂海 · SILENT SEA · 台词对照本（全 12 集）
英文为正文原句，中文为大意，仅用于审稿；人名一律用英文。
场标与集内编号与《第 N 集.txt》一致。


========================================
第 1 集：退潮
========================================

【1-1 昏 外 干涸航道·沙脊】
Lena（无线电，平，语速偏慢）[VO]
　EN｜Three barrels. The winch, not the hold.
　CN｜三桶水。换的是绞盘，不是货舱。
```

规则：

- **EN 必须与正本逐字一致**（含 `…`、缩写、标点）；说话人与语气提示也照抄。
- CN 是中文大意，供审稿与配音参考，不要求逐字对应。
- 对账口径是**比正文**：只比说话人名不算查过（说话人对、台词换了照样是错）。
- 中文映射按「(集号, 英文原句)」保存：脚本重建时先取现有对照本的中文，再取项目里的补充映射，
  都没有就写成 `（待补）` 并在结尾列出——列出多少条，就是还欠多少条中文。

补充映射文件放在项目根目录，文件名 `<剧名>-台词中文映射.txt`，每行一条、用全角竖线分隔：

```text
12｜She'll float before I open that door.｜门我不会开，船照样会浮起来。
```

新建或改写台词的正确顺序：**先写正本 → 在映射文件里补中文 → 重建对照本**。
重建只动对照本时用 `--only reference`（同理 `--only sheet` 只重建场次表）。

## 2. 分集场次表

三段结构：

1. **总览**：每集场数、台词数、时间分布（日/昏/夜/晨）、场景清单与出现次数。
2. **场景使用统计**：按出现场次排序——资产做几张场景图、排期怎么布景看这里。
3. **逐集场次表**：集头块 → 集标题 → 一行一场：

```text
1-1 ｜ 昏 外 ｜ 干涸航道·沙脊
　　人物：Rune、Lena、塔楼守卫群像
　　物件：斧　｜　台词 10 句
```

“物件”由脚本按关键词表（弓／箭／刀／斧／水囊／水桶／钢缆／铁爪／账板／鞋／电台…）从动作与台词里扫出来，
用于道具分派；关键词表可以用 `--props` 追加。

## 3. 常用命令

```bash
# 重建两份派生件（分集场次表覆盖，台词对照本保留已有中文）
python3 scripts/build_derived_docs.py <项目目录>

# 只体检不写文件：场次表差多少场、对照本缺多少中文
python3 scripts/build_derived_docs.py <项目目录> --check

# 交付打包（自带一致性校验与 SHA-256）
python3 scripts/pack_delivery.py <项目目录> --label r2
```

## 4. 三条纪律

1. **改完正本立刻重建**：台词、场号、场头时间任一变化都会让派生件过期。
2. **改动按集定位**：需要手工改对照本中文时，按「集号＋英文原句」定位，
   不要用整句全局替换——跨集重复句会被改错行。
3. **扫正文要含续行**：动作行换行后的续行同样承载人名与光源，逐条检查时不要只看 `△` 开头的行。
