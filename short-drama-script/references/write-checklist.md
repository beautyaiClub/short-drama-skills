# 写作自检清单

左栏是这套流程里真实翻过车的症状，右栏是防止它再次发生的动作。写每一集时按这个顺序过。

## 一、写之前（对表）

1. 读整体大纲里这一集的条目 ＋ **逐日时间锚点**：这一集从第几天开始、到第几天结束。
2. 读上一集结尾的最后一句台词或最后一个动作——这一集开场必须是它的直接结果。
3. 逐项抄下这一集要动的账：箭／弹／水／油／人数／天数／伤情／道具位置。
4. 读全局设定的资产命名表：这一集要用到的场景、人物、道具都必须已有 ID；
   新资产先补进命名表再写剧本。

## 二、写的时候（逐场过）

| 症状 | 防止动作 |
|---|---|
| 说明文字里出现“他／她”，分镜认错人 | 概要、大场面、动作行、语气提示一律写人名 |
| 场标题只写母场景名，分镜把同一套景生成几十次 | 每场都写到子视图：`山谷营地·水塔下` |
| 场头时间写出“清晨／深夜／夜／晨” | 只允许 `日／昏／夜／晨` 四个词 |
| 一场里从夜走到晨、或中途换了地点 | 拆场。切空间就换场号，一场＝一个连续时空 |
| 场头写“夜”，正文首句是“天刚亮” | 场头跟随正文改；两者必须指同一个画面 |
| 场外人声没标 `[VO]`，配音按现场口型处理 | 无线电／喇叭／画外／远处传来一律标 `[VO]` |
| 整场夜戏没说光从哪来，分镜没有布光依据 | 夜戏点明实体光源：火／灯／月／炉／焊枪／车灯 |
| 时间变化的接缝处，新场开场没交代过了多久 | 新场第一句给时间承载：火矮成炭／天光／血干了／只剩几盏灯 |
| 同一时间换了地点，人凭空出现 | 开场补到场动作（“从缺口那边走回营地”“从沙丘后面绕上来”） |
| 战斗还在打就切到天亮在收尸 | 补一句战果收束（对方退走／车退出射程／营地里没有人喊） |
| 数值打架：上一场“108 支箭”，下一场“200 支” | 每集结尾把账重算一遍，改一处就回头改大纲与设定 |
| 后面用到的道具前面从没交代过 | 给每个关键道具列状态表（谁拿着／在哪／什么状态），第一次出现就交代 |
| 来源错代：“第五集留在车尾轴上的铁爪”其实是第七集 | 引用历史事件时回原文核对集号与场号 |
| 伤比发生时间早 | 列伤情时间轴：受伤→包扎→单手作战，逐处核对是否都在受伤之后 |
| 角色知道了不该知道的事 | 给每个秘密开“谁知道／什么时候知道”的表，逐场核 |
| 集尾与下一集开场接不上 | 只读相邻两集的“末句＋首句”，问：下一集第一拍是不是由它引起的 |

## 三、写完台词再过一遍

| 症状 | 防止动作 |
|---|---|
| 一集超过 2 句格言／对仗句，像在讲道理 | 只挑每场最后一句和“两个短句对仗”的句子读；超标的换成干活的话 |
| 同一句被不同人物反复说（`What way?`／`Don't know.`） | 跨集统计短句复用；刻意当回声的保留并标注，其余换说法 |
| 台词与同场动作矛盾（动作说“压上来”，收尾写“停下来”） | 以动作为准改提示，以提示为准改动作 |
| 全员一个腔调，连报数字的人都开始说俏皮话 | 给每个角色定语域（短句／数字／命令／交易／孩子），金句只留给转折点 |
| 改了台词之后接话断裂 | 每次改台词，把改动处上下各两句重读 |

## 四、写完之后（收口）

1. 生成派生件：`python3 scripts/build_derived_docs.py <项目目录>`（不许手写派生件）。
2. 跑门禁：`$short-drama-script-audit` 的 `scripts/audit_plain_script.py <项目目录>`，FAIL 必须为 0。
3. 交审查：记录落 `审查/`，**每次审查一个新文件**，不覆盖旧记录。
4. 交付：`python3 scripts/pack_delivery.py <项目目录> --label rN`；确认包内文件与项目当前文件逐字节一致。

## 五、几条最容易忘的硬规则

- 画面里不出现任何可读文字：旗号只用图形，不做字幕，不出水印。
- 载具不是人，不进人物行；人物行不写中文注释、不写分号。
- 群像与发声标签分工：人物行只写 `XX群像`，标签（`掠夺者甲`／`护卫`／`杀手`）只出现在对白行。
- 台词是目标语言原句、人名保持英文；一个项目只允许一种台词语种。
- 改稿前先备份；旧稿不就地覆盖。
