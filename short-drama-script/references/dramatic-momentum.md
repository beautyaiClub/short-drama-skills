# 吸引力与追看动力：写作与阅读检查

适用：创作者要求“不要太平”“要有钩子、爽点”“让人持续看”，或剧本已有事件却缺少推进感时。
这是内容判断方法，不是机械门禁，也不预测市场留存率。摄影、微表情、配乐能表达变化，不能替代变化。

## 先区分三种问题

- **有奇观，没当下压力**：世界很新，观众却不知道此刻需要担心谁、期待什么。
- **有事件，人物没变**：事故很多，策略、关系、代价或知情状态始终一样。
- **有交接，没追看问题**：最后只交代下一项操作，没有把未解决的问题落到人物在乎的结果上。

找出具体段落和前后状态再修改；安静、日常、留白与自然对白本身不是缺陷。

## 写作时的五个判断

1. **开场的承诺是否已经发生？**
   分清观众先知道什么、角色何时发现。奇观可以与异常、欲望、关系摩擦同时进入；世界观VO可保留，
   但检查说明期间是否有正在发展的事。若改为观众先发现危险，要说明角色为何尚未看见，不能牺牲角色能力。
   不强制三秒事故、倒叙或固定钩子类型；必要规则仍要让首次观看者看懂。

2. **升级是否改变局面？**
   对较长的追逐、救援、查证或争执，写下每个主要节点的“原办法—阻力—新办法—结果”。
   将只重复确认同一状态的步骤压缩；保留真正改变选择的疼痛、资源损失、证据边界或他人反应。
   先让观众理解动作，再把时间和强调留给关键变化，不用密集运镜掩盖因果重复。

3. **人物的选择留下了什么？**
   女主主动行动可以只是合理避险，不必每次制造两难。但若行动造成意外分离、失去资源或承担责任，
   后续行为要接住这笔账。合理选择产生坏结果，不等于人物愚蠢或应该自责。
   技术能力也需要可见的局部兑现，不能整集受苦直到外援解决一切。
   将项目承诺的“爽点”写成已经发生的回报：判断被证实、夺回主动、界限被尊重、目标局部实现等，
   具体取决于题材。悬念负责留下问题，回报负责让本次观看值得；不能只加压而始终不兑现。

4. **关系推进是否发生在双方行动里？**
   若目标体验是浪漫、互信或小心翼翼的靠近，标出对方做了什么、主角如何回应、关系因此改变多少。
   例如主角要求等待，对方改变自己的操作并承受等待的负荷，主角才继续配合：关系变化与任务同场发生。
   不是每集必须救人、拥抱、冒险或亲吻；任务后的日常停留也可以完成关系推进。

5. **结尾留下的是操作，还是在乎的结果？**
   写出当集已经兑现的局部回报，再用一句普通话描述观众尚想知道什么。
   若只能回答“接下来修设备／换地点／查资料”，检查该操作关系到谁、可能失去什么，以及最后画面是否承载了它。
   可用未结代价、新线索、关系后果、矛盾事实或有意余韵收尾；不要求每集再来一次事故。
   不能靠角色无故隐瞒必要信息，或在成功前一帧硬切，代替真正的悬念。

## 修改后查两条接缝

- **节奏接缝**：把全场主要节点并排看，不能每步同样长、同样重。喘息应处理刚发生的后果；局部胜利可以完整保留。
- **信息接缝**：把后集线索前移时，同步本集出口、下一集入口及该线索后续升级；“似乎有回应”不等于确认身份或生还。
  后次出现应增加位置、身份、可行动性或解释约束，不能重复同一发现。先查已有世界规则，避免补出新能力或便利装置。

## 审查如何落纸

每项写“位置与证据 → 观众可能感受到的影响 → 必须改变的状态”，并注明判断边界。
规划场次秒数只能支持节奏假设，不能冒充试读、预演或观看测试。没有固定时间点、反转数量、台词比例或通用留存分数。
格式与派生件通过只说明文档可解析；不等于剧本有吸引力，也不等于目标市场验证。
