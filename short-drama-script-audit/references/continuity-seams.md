# 接缝与动作顺序

用于写/改单集后的自检、接缝专项审查，以及补写摄影、微表情或VO后的回归。
核心故障：原动作已经写完，新增表演又从动作开始前重写；或反应已发生，触发它的对白还排在后面。
此类问题须通读语义，不宣称现有机械脚本能自动判定。

## 1. 看正文里的时间，不只看场头

- 每个相邻场读“上场末段→下场开场”，核对上一轮问答/动作是否结束、承接或被明确中断，
  下场在何时何地、人物如何到场、带着什么。未完的同一次对话不能无承载地从白天延续到夜晚。
- 一场内写到“另一日午后”，即使前后场头都写“日”，也要分场；不能用“时间省略后”掩盖跨日。
  同一段行动的短暂等待、安装或洗漱可明确省略，以耗时后的可见状态承接。
- 时间变化放进能拍到或听到的正文：天光、灯光、衣服变化、食物消耗、到场动作或必要字幕/台词
  （遵循项目文字展示约定）。只在大纲、制作前言里声明“数日后”不足以保证清洁合集和成片看得懂。
- 单元段子允许下一次约会、另一天的新事件，不强迫接续上一秒；仍须交代新时空，并保留前集的钥匙、
  遗留物和约定。闪回有进入/退出及回到当前状态的承载时，不按时间倒流误报。

## 2. 追踪动作完成后的状态

对本场有戏剧作用的道具、人物站坐和交接，简记状态变化；不要求为每件背景物建账。

| 发生点 | 人物位置/姿态 | 道具：谁拿、在哪、开合/使用状态 | 未结动作/问答 |
| --- | --- | --- | --- |
| 开场 | 门口站立 | 钥匙在手，包在肩 | 入屋 |
| 收钥匙后 | 屋内站立 | 钥匙入包，双手可空出 | 对方递抹布 |
| 接物后 | 同位置 | 抹布在手，钥匙仍在包 | 接不接受打扫请求 |

- 状态变化需要相应动作或清楚的省略承载：钥匙已经入包，后镜不能直接握钥匙；手机留卧室桌上，
  到玄关收包前须已取回或携带。不要为普通生活省略补拍全程，补足关系到误会、藏物和连续性的关键一步即可。
- 交接方向一致：丈夫递空袋→女主接稳→丈夫松手；下句不能突然写丈夫接袋，除非有反向交还。
- 合抽屉后若未重开，不再写“还没关”；已放杯不再写“手持杯停一下再放”；已接通不再写“先静音再接”。
- 离场后返回须有时间/路径/到场承载。相邻空间可一句“挂断后从玄关回到卧室”，不必补无戏的走廊场。
- 手部操作与受力符合状态：先放杂志再双手拉近，先放工具再拥抱；台词说“踩着”时不能实际只用肘压住衣服。

## 3. 按触发顺序读对白、动作、VO

- 每个问题沿后文找到实际回应：台词回答、清楚的点头/摇头、行动回应、明确拒答、打断或延后均可。
  没有回应且原因不明才是失接；故意回避或“之后讲”不强行补标准问答。
- 依赖外界信息的反应顺序：对方提出/做出→角色听见/看见→面部/身体反应及VO→后续选择。
  “听见他答应等待而开心”的VO不能排在承诺发声之前；“谢绝加餐后收回食物”不能排在谢绝之前。
- 允许提前猜测、误读和内心预演，但写成“猜想/期待”，不能写成已经听见尚未发出的那句话。
  允许对白提前起声或声音跨切，须明确声源与起止；不能默认一句台词自动在前面播放。
- 问答或动作跨切时说明声音是否连续。若已跳到当晚重提同一问题，应是新一轮交流，不能伪装成上一句的即时回答。

## 4. 补写段落的回归方法

1. 不把新动作段整段堆在原动作之后。找到原动作发生点，合并成一次完整执行，或把新增镜头改为完成后的承接状态。
2. 从本场首行读到末行，检查“开始→进行→完成”有没有倒回；再读上场末段、下场开头。
   只重读新加的几行不足以发现此前已合抽屉、已起身、已接电话。
3. 同一动作的近景覆盖可写“承接上镜，手已停在合拢抽屉上”；不要再次写“伸手合抽屉”。
   如确需重播、闪回或不同时间重复行为，明确标出并给返回当前的承载。
4. 改时间/场号回看本集所有接缝及相邻集；改关键道具回看其来源、移动和兑现；改问答回看上下至少两句及实际回应。
5. 确认正本后再重建场次表、台词映射/对照本、全集和交付包。字节一致只说明复制正确，错误也可能被一致复制。

## 5. 审查记录与判断边界

按项目审查记录规范逐项给出：位置、前后两处原文、状态/问答缺口、影响、最小修订目标和状态。
明确矛盾记必须修；可能是覆盖镜头或正常省略但未写清的，记执行歧义并说明缺什么依据，不凭怀疑报FAIL。

报告区分：机械格式结果、人工内容结论、派生件一致性、试读/现场预演结果。没有逐场通读不能称连续性已通过，
没有独立审稿人则写作者自检。下列应作为阅读校准例，不是靠关键词自动报错的规则：

| 文本情况 | 判断 |
| --- | --- |
| 同场“隔日送礼”之后又写“另一日午后使用礼物” | 跨日须拆场并交代新到场状态 |
| 已关抽屉，后段再次关抽屉且无重开 | 状态回退；合并一次动作 |
| 先写拒绝后的收回动作，后排拒绝对白 | 触发顺序倒置；先回应后反应 |
| “当前→此前闪回→回到同一手持道具构图” | 承载明确则成立，不误报跨时错误 |
| 被问原因后明确“之后说，现在先握我的手” | 有意延后且推动动作，不判问答遗失 |
| “已安装好、旧帘收妥”接短暂安装省略 | 同次行动耗时明确，不要求全程展示 |
| 单元剧下一集“另一个休息日”开始新约会 | 可成立，核对未重置关键物件/约定即可 |
