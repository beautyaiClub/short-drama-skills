# 纯剧本格式标准（场次本）

这是本套工作流的目标格式。项目里如果有别的写法，先按这份对齐再谈内容。

## 0. 一句话

剧本只管“戏”。集头交代这一集的账，正文按“场”往下排；**一场 = 一个连续时空**，
场里只有三样东西：人物行、`△` 动作行、对白行。
镜号、景别参数、机位、焦段、运镜、每场时长、集内镜数、场次表一律不写——那是分镜层的活。

## 1. 文件

- 纯文本 `.txt`，UTF-8，无 BOM，无 Markdown 标记。
- 一集一份，文件名 `第N集.txt`（N 用中文数字：第一集、第十一集）。
- 配套三件（推荐齐备）：`<剧名>-全局设定.txt`、`<剧名>-第一季整体大纲.txt`、
  `<剧名>-台词对照本.txt`；`<剧名>-分集场次表.txt` 由脚本生成。

## 2. 集头区（三层，顺序固定，不能乱）

一集的开头分三层，从上到下：

```
<剧名> · <英文名>

本集概要：…（3–6 句中文；说明文字不出现“他／她”，一律用人名）
【本集大场面】
· <场号范围> <大场面名>：必须看到什么（规模与比例参照、物理后果；不写运镜）
· …
本集人物：名字、名字、……（这一集出现过的全部人物；顺序：主角 → 群像 → 反派）
本集场景：场景名；场景名；……（这一集用到的全部场景）

第 N 集：<集名>
(人物名称英文 · 台词英文；场景、动作与语气提示为中文)


【1-1 日 外 <母场景·子视图>】
…
```

| 层 | 内容 | 规则 |
|---|---|---|
| **文档头** | `<剧名> · <英文名>` | 全文件第一行，只标作品，**不带集号**；脚本靠它取剧名与英文名（打包命名用）。剧名没有英文名时只写剧名（例：`黑戒`） |
| **概要块** | 本集概要 → 【本集大场面】→ 本集人物 → 本集场景 | 四块按这个顺序，**整块放在集头块上面**；这是给统筹／美术／资产看的账 |
| **集头块** | `第 N 集：<集名>` ＋ 语言声明行 | 放在概要块下面、正文第一场之前；语言声明是括号开头的那一行 |

为什么这么排：先读完“这一集讲什么、必须看到什么、有谁、在哪”的账，再落到“这是第几集”和语言分工，
最后进正文。脚本按形状解析（文档头＝第一行；集头块＝`第 N 集：<集名>` 行；概要块＝两者之间的内容）。

老顺序（`<剧名> · <英文名> · 第 N 集：<集名>` 挤在第一行、概要块在集头块下面）仍然读得懂，
审查会提示迁移——新写的稿一律用上面这一版。

## 3. 场标题

```
【N-M 时间 内／外 场景】
```

- `N-M` = 集号-场号。**场号从 1 开始连续**，切空间就换场号，同一空间连续算一场。
- 时间只允许 **日／昏／夜／晨** 四个词。不许出现“昼”“清晨”“深夜”“夜／晨”这类自造写法——
  它是分光与调色的开关，必须是一个封闭集合。
- 内／外只允许 **内／外**。
- 场景写资产规范名。**同一母场景必须带子视图**：`干涸航道·沙脊`。
  只写母场景名等于让分镜把同一套景重复生成几十次，是“场景单调”的第一原因。
- 载具取景也走资产：`PR-01 拖船·驾驶舱`、`PR-01 拖船·货舱`。

## 4. 场下三件套

```
人物：名字、名字、……

△（景别）动作……

角色名（语气或策略提示）：台词
```

- **人物行**：只写资产命名表里的人名，或已登记的群像名（`营地女战士群像`／`掠夺者群像`／`被掳者群像`）；
  顿号分隔；不写中文注释（不写 `Rune（拖船内）`）；载具不是人，不进人物行。
  这一行就是"这一场必须出现在画面里"的名单。
  **开口的无名角色不写在这里**——他们用项目声明的发声标签（`工人甲`／`守卫乙`…），
  标签只出现在对白行；人物行写承载他们的群像名。标签表见 `project-layout.md` §4。
- **动作行**：以 `△` 开头，一行一个动作节拍，只写看得见、听得见的东西。
  括号里只给景别（远景／中景／近景／特写／快切），必要时加**一个**运镜词（`（近景·推）`）；
  不写机位、焦段、时长。每个动作要有明确的结束状态：“转身”不算，“转身四分之三停下”才算。
- **对白行**：`角色名（语气或策略提示）：台词`。台词是目标语言原句，提示是中文。

## 5. 命名与标记

- 人名一律用资产表的写法，全剧不出现第二套叫法；剧本其他位置也不出现译名。
- **场外人声要标 `[VO]`**：无线电、电台、录音、喇叭、电话、从画外／远处传来的声音。
  漏标的后果是配音阶段把它当现场口型处理。
- 说明文字（概要、大场面、动作行、语气提示）里**不出现“他／她”**，一律用人名——
  分镜与人物识别靠名字，代词会让分析系统认错人。
- 画面里不出现任何可读文字（旗号只用图形，不做字幕）。

## 6. 禁止项

出现任意一条即格式不合格：

`镜号`／`景别：`／`机位`／`焦段`／`时长：`／`画面：`／`声音：`／`衔接：`／`运镜：`／
`场次表`／`生成单元`／`本场时空气氛`／`镜头纪律例外`／场标题里的时间自造词／
人物行里的中文注释或分号。

## 6.5 台词工程（决定配音节奏与海外可用性）

台词不只是信息，它是**配音和视频模型的节奏谱**，也是**这个项目面向谁**的分水岭。
先跟创作者定一件事：**这套台词是给国内竖屏看，还是给海外看**——两种口径不能混着写。

### 6.5.1 两种口径，先选一个

| 口径 | 金句 | 台词的任务 | 用什么传 |
|---|---|---|---|
| **国内竖屏** | 每集给 **2–3 句金句预算**（反击句／狠话／定调句），要能被截图、被复述 | 打得响、记得住 | 台词本身（观众复述台词） |
| **海外／电影级** | **禁止金句**：一句能被截图的话，在海外观众眼里往往是"剧本在替人物说话" | 信息落地、关系施压 | 场面（观众复述画面，不复述台词） |

判据只有一条：**这句话是"人物在当下会说出口的"，还是"作者想让人记住的"**。后者删。

### 6.5.2 标点就是节奏谱（四＋一）

标点决定配音在哪里顿、在哪里挑高、在哪里拖长；**一集里标点必须有起伏，全句号＝一集平的**。

| 标点 | 中文短剧 | 英文（海外／电影级） | 读出来是什么 |
|---|---|---|---|
| `。` / `.` | 陈述、报数、**按住的狠话**（越狠越用句号） | 同上；寡言主角的短句一律句号，那是他的性格 | 平、稳、不留缝 |
| `？` / `?` | 疑问、反问、试探 | 追问、审问、把球踢回去 | 尾音挑起来 |
| `？！` / `?!` | 被噎住、当场失态、又惊又怒的短句（全季十来处） | 罕见；只在失态那一拍用 | 先挑后砸 |
| `！` / `!` | 吼、喊、命令、拍桌子、破音 | 命令、打断、喇叭喊话 | 直接砸下去 |
| `……` / `...` | 犹豫、没说透、认命 | **英文里这是"犹豫／断气"的标准写法，全季要有 40–60 处** | 拖长、断在中间 |

三条硬规矩：①狠话用句号，不吼；②金句（若本项目允许）不加感叹号；③省略号只给**短句＋犹豫提示**，
长句一律句号——把长句改成省略号是"假犹豫"。

### 6.5.3 单句长度（拆句不压戏）

- 中文单句 **≤35 字**；英文单句 **≤62 字符**（含标点）。
- 超了就拆成两句，第二句提示写"（……，接着）"：`A（平）：前一句.` ＋ `A（平，接着）：后一句.`
- 拆句要**迭代**：拆一次还超就再拆；没有句边界的，按最后一个逗号拆。
- 一次呼吸说不完的句子，配音会糊、口型也对不上——拆句不是压台词，是把气口还给演员。

### 6.5.4 海外口径的四条硬规矩

1. **抽象名词每集 ≤1 次**（freedom／everything／nothing／nobody／forever 这一类）。
   要用就用**具体的东西**替换：水、桶、油、螺栓、插销、坡道、天数、人数。
   反面：`The machine. Freedom.` → 正面：`This runs the pump. The pump keeps the well. That's the trade.`
2. **每一场至少一句"信息落地"**：谁对谁说了什么、对方拿它**能做什么**。
   只表态不落信息的应声句（`Noted.`／`Yeah.`／`Sure.`）能删就删。
3. **内心独白 OS：每三集 ≤1 处，或每集 1–2 处——按项目口径二选一，写进《全局设定》**。
   海外口径取前者（全季 ≤10 处）；国内竖屏取后者。OS 只写**具体的东西**
   （`Her boots had sand from outside the gate.`），不写结论（`Somebody in this camp carries for them.`）。
4. **禁止宣誓与预言**：不许"我发誓／总有一天／这世上"，也不许对仗句收尾
   （`One grave today. Tomorrow I start on theirs.` 这种一律改掉）；除非某个角色的性格就是预言式，
   那也只给他一个人。

另外两条口径：**允许不回答**（审问场面里人物可以不接问题、答非所问，写作上用破折号 `—` 截断）；
**短句要带新信息**——同一个"嗯／对／知道"在一集里出现两次以上就该删。

### 6.5.5 集尾钩子不许落在空镜上

一集的**最后一拍**必须是一句台词或一个没做完的动作（`尾钩`）。落在空镜、道具特写、环境描写上，
观众拿不到"必须点下一集"的理由。审查判据：看每集最后一行——如果是 `△` 环境行，这一集算没钩子。
（允许的例外只有两种：黑屏后的 `OS`、以及刻意留白的强画面对照，且必须写进审查记录。）

## 7. 长度与节奏口径

**先声明规格，再按规格反推剧本量——不要先写完再看多长。**
在《全局设定》里写一行：`成片规格：单集 90 秒（±5 秒）· 竖屏 9:16`；
审查脚本读这一行校验每集篇幅。算法、校准与自查工具见
[timing-model.md](timing-model.md) 与 `scripts/estimate_duration.py`。

常用规格 ⇒ 一集该写多少（正文＝动作行＋对白行的字数）：

| 目标成片 | 正文字数 | 对白 | 可演动作（▲ 行） | 分镜 |
|---|---|---|---|---|
| **90 秒** | 950–1050 | 16–20 句 | 13–16 条 | 8–10 个 |
| 2–3 分钟 | 1500–2300 | 25–45 句 | 20–35 条 | 15–25 个 |
| 4–5 分钟 | 3100–3900 | 50–70 句 | 45–60 条 | 30–40 个 |
| 11 分钟 | 7000–11000 | 100–200 句 | 100+ 条 | 60+ 个 |

三条硬约束：

- **一场 = 一个连续时空**（同上一节）。它不只是剧作规矩：逐小场算再相加，时长会往上走，
  所以拆场等于加时长。
- **时长由动作数决定，不由台词数决定**：动作主导时台词只按半价计入。
  要拉长就加 `▲` 的可演动作，要缩短就先砍动作。
- **每一集都要有**：一个开场钩子（前 6 秒）、一次转折或当众碾压、一个集尾钩子。
  集尾钩子的最后一个动作或最后一句台词，必须是下一集开场的直接原因——
  中间不许出现可以整段删掉也不影响下一集的“安稳的一夜”。

夜戏比例：全季 ≤30%（夜戏在 AI 生成里最难做，且连看两集夜景会疲劳）。

## 8. 最小样例

```
寂海 · SILENT SEA

本集概要：退潮时分，Rune 的拖船被困在干涸的航道里，远处灯塔的探照灯扫过船身。
Lena 带着两个人从沙脊上下来，要用三桶淡水换船上的绞盘；Rune 答应修好绞盘，
但不肯交出船舱钥匙。夜里潮水回来，两边一起把船拖出沙脊。
【本集大场面】
· 1-2～1-4 拖船搁浅：船体比人高出三个身位，龙骨陷进沙里，涨潮时整条航道的水一次涌上来。
· 1-6 绞盘拉船：两根钢索绷成直线，把船从沙脊上硬拖回水里。
本集人物：Rune、Lena、塔楼守卫群像、拾荒者群像
本集场景：干涸航道·沙脊；拖船·驾驶舱；灯塔·底层

第 1 集：退潮
(人物名称英文 · 台词英文；场景、动作与语气提示为中文)


【1-1 昏 外 干涸航道·沙脊】
人物：Rune、Lena [VO]、拾荒者群像

△（远景）退潮后的航道摊开成一片碎贝壳与盐壳，拖船斜插在沙里，桅杆上是唯一还在动的东西。
△（近景·跟）Rune 踩过盐壳走到船首，蹲下，用手掌量了一遍龙骨陷进沙里的深度。

Lena（无线电，平，语速偏慢）[VO]：Three barrels. The winch, not the hold.
Rune（低声，说给自己听）：She'll float before I open that door.
```

## 9. 从别的格式整改过来

1. **先拆集头**：把旧头部声明（段数／镜数／时长／语言／夜景理由）里**有制作价值的部分**搬去集头块
   （概要、大场面、人物、场景），其余丢弃。
2. **再拆场**：镜头块按“时空是否连续”合并成场，套场标题；镜号删掉，不要保留成场号。
3. **内容不许丢**：旧稿的动作与台词逐条搬进新场，只换外壳；漏台词是最常见的整改事故，
   必须用台词账逐条对账（见 `references/derived-docs.md` 与审查 skill 的机械校验脚本）。
4. **最后补两件事**：给每场写人物行；给场外声补 `[VO]`。
5. 整改完把旧稿整份留档（`备份-<节点>-<YYYYMMDD>/`），不要就地覆盖。
