# 多集联合回归

创作者要求每三集检查、连看多集是否平淡或确认持续追看时使用。默认三集一批，可按项目约定调整。
读取本批完整剧本、前批末场和下一集已有开场或地图；未写出的剧本不能按已完成计数。

每集填目标、阻力、选择、局部回报、未结代价、尾钩及下集承接，再跨行检查：

- 人物语域、称呼与礼貌程度是否跟关系一致，台词是否重复解释、翻译生硬、接话断裂。
- 女主的行动、代价与关系有无累积；是否连续几集都只是别人救她或给她答案。
- 前集问题后集如何处理；线索再次出现有无位置、身份或可行动性增量，还是换说法拖延。
- 是否既有吸引继续看的未知，也有已经兑现的成功、亲近或理解；不把安静等同平淡。
- 时间、伤情、道具、资源和信息权限是否逐接缝成立；检查来源、验证及证明边界。
- 摄影与动作是否可执行，时长是否只是规划；检查整合稿并非按导演说明字数估计成片。
- 地图和派生件是否仍对应当前正本，批次结尾是否把下一批入口吊空。

每项问题仍须位置、证据、影响、owner与修订目标。联合回归不引入固定反转频率、通用留存分数或审批。
审查只交问题；已有明确修订授权时由写作工作单元修改，再回看问题与波及范围。标明独立审稿或作者自检，
保留每轮记录，不将机械通过、作者回看和母语/样片验证混成一个“通过”。
